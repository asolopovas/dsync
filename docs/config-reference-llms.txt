Dsync config reference for agents

Default path: dsync-config.json. Override with -c/--config.

Fields:
- sshHost: SSH target for ssh and rsync, usually user@host.
- port: SSH port string.
- remote.db: DB used by remote mysqldump/mysql.
- local.db: DB used inside local Docker Compose mariadb service.
- remote.host/local.host: present, not used by current commands.
- dbReplace: ordered {from,to} list; empty means stream DB unchanged.
- sync[].remote/local: directory endpoints; trailing slash normalization is required.
- sync[].exclude: rsync --exclude patterns.
- sync[].replace: optional bool. When true on forward sync, apply dbReplace values to text files (.css/.js/.json/.html/.svg/.xml/.txt/.map/.php/.twig) after rsync. Use for generated WordPress asset CSS that contains absolute remote URLs.

Forward WordPress DB cache behavior:
- Dsync derives and deduplicates WordPress roots from sync[].local paths containing a wp-content directory.
- Before import, every root must exist with wp-load.php and wp must be available on PATH.
- After a successful import, Dsync runs a site-scoped WP-CLI object-cache flush once per root.
- Reverse, file-only, and non-WordPress syncs do not flush caches.
- There are no cache flags or config fields.

Forward replacements: from -> to in listed order.
Reverse replacements: to -> from in reverse list order.

Engine selection is automatic: no replacements -> none; WordPress-looking paths -> go-serialized; otherwise raw. Serialized validation is on by default; guid is skipped by the serialized-safe engine. Do not add legacy dbReplaceEngine, validateSerialized, or skipColumns to new configs.

Validation is operation-aware: SSH host and numeric port (1..65535) are required for sync; file sync requires directory endpoints; DB sync requires local.db and remote.db. Unknown JSON fields remain accepted. Unsupported replacement engines and empty effective sources (to in reverse DB sync) are rejected before dispatch. Generated configs are exclusive 0600 files. Exclusions also govern destination file replacements; symlinks and nonregular files are skipped.
